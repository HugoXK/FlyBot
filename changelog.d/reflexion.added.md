A Bot now learns from a failure that repeats. When a tool call keeps erroring, or a model call fails several times in a row, the Bot writes itself a short note ("the tool \"X\" has failed several times…") into its own memory, so its next conversations avoid the loop. The note goes through the normal memory path — size-capped, secret-scanned, visible in the memory panel and removable with `forget` — and is written at most once per failure per day. Set `reflexion: false` to turn it off.
