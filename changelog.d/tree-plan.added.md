A tree coordinator can now keep a delegation plan. `set_plan(goal, parts)` records the split before it delegates, each child reports progress with `report_part` (todo / doing / done / blocked), and `read_plan` shows a Bot its own plan and the one its parent gave it. The coordinator's prompt shows the plan as one line — what is done, what is still open, and what is blocked — so a split task is tracked instead of held in one prompt's memory.
