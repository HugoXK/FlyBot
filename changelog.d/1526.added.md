**Workflow failure recovery:** A node can now recover from failure by returning to an upstream node and retrying, instead of stopping the run. Define a failure recovery edge with `onFail: true` pointing from the failing node back to the recovery target, with a configurable `max` bound on recoveries (1–8, default 3). Example: `{ from: 'review', to: 'draft', onFail: true, max: 3 }` — when Review fails, the workflow resets the body from Draft through Review and runs it again, up to three recoveries. After the recoveries are used, the run fails cleanly. Does not interfere with existing `failOnce` retry or success-path `loop` edges.
