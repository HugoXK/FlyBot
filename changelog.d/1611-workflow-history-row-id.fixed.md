An attempt a Workflow graph edit stops no longer loses its `superseded by` marker: the history row that edit writes now carries the id of the run it ended, so once the same task is handed to the workflow again the Runs tab names the stopped attempt as superseded by the retry. A legacy demo record that stores a run id keeps it in the migrated row too ([#1611](https://github.com/ThinkFlowLab/FlyBot/issues/1611)).
