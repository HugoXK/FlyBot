An approval card for a held `FLYBOT-ROOM-SHARE` line now keeps the line's own text when it contains a `}` or an escaped quote: the envelope tail is read as JSON with its strings and escapes tracked, instead of stopping at the first brace. A line whose body was unreadable before falls back to the same plain sentence as now, and a malformed face-room tail keeps its words without the `to the room:` prefix ([#855](https://github.com/ThinkFlowLab/FlyBot/issues/855)).
